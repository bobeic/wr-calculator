# Champion guides

One file per champion, named by the champion's id (the end of its page URL): `ambessa.md` for
`/champions/ambessa/`. Copy `_template.md`, rename it, and fill in what you know; leave out any section you have
nothing for. The champion page shows the guide under the builds, and the AI coach (later) reads the same files.

Formatting is deliberately small:

- `## Heading` starts a section. Use the headings from the template so every guide reads the same.
- A blank line separates paragraphs.
- Lines starting with `- ` are a bullet list.
- `**bold**` for the one thing to remember.
- Under `## Matchups`, start each bullet with the opponent's name and a colon (`- Darius: ...`); the page shows the
  opponent's icon and links to their page. Names are matched the way they're written on the site.

Write it the way you'd explain it on stream: what to do, and why. Numbers the site already shows (win rates, item
stats) don't need repeating.
